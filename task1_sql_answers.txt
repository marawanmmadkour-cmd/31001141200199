--- Reflection: Web Page Data vs Database ---
Working with data from a web page is very different from querying a database:
1. Databases have a fixed, structured schema and can be directly queried with SQL, while HTML pages are designed for display, so data is wrapped inside HTML tags.
2. Web scraping is sensitive to layout changes; if the HTML tags or CSS classes change, the code breaks, unlike stable databases.
3. In this task, combining both required renaming web columns (e.g., 'Member ID' to 'member_id') and handling missing values like 'return_date' to align with the main database schema.
